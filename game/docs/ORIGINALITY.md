# Originality statement

Spire Sprint is inspired by a **genre** — early-2000s, momentum-based vertical tower jumpers in which speed
decides jump height, several floors can be skipped at once and combos reward risky routes. Genre conventions and
game mechanics are shared by many games; everything *expressive* in this project was created from scratch for it.

## What is original

| Area | How it was made |
| --- | --- |
| **Title and logotype** | Name “Spire Sprint”. The lettering is drawn from stroke paths in `tools/art/ui_art.py` (chamfered geometric letters, the *I* is a spire with a star) — not an installed or downloaded font. |
| **Protagonists** | Seven original characters — Pip (fox-kit courier), Bolt (clockwork robot), Moss (leaf-hatted frog), Nova (star-child), Wraith (a very polite ghost), Ember (flame-tailed lizard), Zenith (storm-crowned knight). Every frame of every animation (10 animation rows each) is rendered by the vector rig in `tools/art/rig.py`, `characters.py`, `cast.py`, `poses.py`. |
| **Tower themes** | Eleven environments (Moss Vaults, Forge Deck, Neon Grid, Overgrown Spire, Prism Cavern, Clockwork Hall, Tempest Deck, Lumen Lattice, Auroral Terrace, Starwell, Zenith) — parallax layers and wall strips are generated by `tools/art/themes.py`; platform styles are drawn in code (`src/view/platform_view.gd`). |
| **User interface** | Built entirely in code (`src/ui/ui_kit.gd`): colours, rounded cards, buttons and widgets are defined there. No UI kit, icon pack or theme asset is used. |
| **Sound effects and music** | Synthesised by `tools/generate_audio.py` (oscillators, envelopes, filtered noise; two original compositions with their own chord progressions, bass lines, arpeggios and melodies). No samples, recordings or loops from any library. |
| **Launcher icon** | `icon.svg` and `assets/icons/*` — a spire, floating platforms, a scarf swoosh and a star, drawn by `tools/art/ui_art.py`. |
| **Code** | All GDScript, the Python reference simulation and the tooling were written for this project. Level generation, physics, control schemes, scoring, replay format, save system and UI flow are implemented independently. |
| **Text** | All in-game text, praise messages (“SKY HIGH!”, “LEGEND OF THE SPIRE!” …), help and tutorial wording. |

The generators are deterministic (fixed seeds), so every bitmap and sound in `assets/` can be reproduced and
audited by running them; the *source of truth* for the art and audio is the code in `tools/`, not the exported files.

## Distinct identity by design

* Own name, characters, lettering, colour palette and world (a tower of eleven themed environments).
* Own control scheme details: hold-to-run **and release-to-jump** touch zones with a minimum-hold filter, an alternative
  **tilt + tap** mode with calibration, sensitivity presets and sensor lifecycle protection.
* Own systems: seeded reachable tower generation with a provable reach guarantee, deterministic 120 Hz fixed-timestep
  simulation, replay format, staged “surge” scrolling, `floors²` combo bonus, custom character packs.
* Own presentation: spring-driven squash-and-stretch, a verlet scarf that shows speed and direction, procedural
  particles, theme colour blending.

## Before you publish

This document describes how the project was made; it is not legal advice. Before releasing under a store listing:

1. Search the app stores and trademark databases for “Spire Sprint” and the character names; rename if needed
   (the name appears in `project.godot`, `export_presets.cfg`, `src/` UI strings and the logo generator).
2. Add a licence file for your own code and art (none is included).
3. Keep the in-game *Licences* screen (it satisfies Godot's attribution requirement).
