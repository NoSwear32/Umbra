# Umbra

A premium, dark-mode AI productivity dashboard built with Next.js 15, TypeScript, and Tailwind CSS. Umbra brings three focused workspaces — **Orb**, **Sage**, and **Manic Heart** — together under one calm, futuristic interface.

## Stack

- [Next.js 15](https://nextjs.org/) (App Router)
- TypeScript
- Tailwind CSS
- No external UI/icon libraries — all icons and charts are hand-built SVG components

## Getting started

```bash
npm install
npm run dev
```

Then open [http://localhost:3000](http://localhost:3000) — it redirects to `/dashboard`.

## Routes

| Route | Description |
| --- | --- |
| `/dashboard` | Main overview — stats, recent activity, account & notification previews, module usage, insights |
| `/orb` | Focus session workspace with an animated orb visualization and recent sessions |
| `/sage` | Conversational AI insight workspace with chat, insights, and saved conversations |
| `/manic-heart` | Pulse/signal monitoring workspace with history and sensitivity controls |
| `/account` | Profile, plan, billing, and security details |
| `/settings` | Tabbed settings — Account, Notifications, Appearance, Privacy, Security |

## Build

```bash
npm run build
npm run start
```
